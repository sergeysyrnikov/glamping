# Pinewood Glamp — лендинг глэмпинга

Одностраничный лендинг глэмпинга «Pinewood Glamp» (Тульская область, Козельский район, озеро Сосновое, 90 минут от Москвы). Статическая страница на чистых HTML/CSS/JS без сборщиков и зависимостей, подготовлена для размещения на Тильде (используются её CSS-классы `t-*`, атрибуты `data-vibeblock-*` и хуки `window.tildaForm`).

## Структура страницы

Лендинг состоит из восьми секций (каждая помечена `data-section-name`):

| Секция | Описание |
| --- | --- |
| Навигация | Фиксированная шапка с адаптивным состоянием (прозрачная на обложке → светлая при скролле), бургер-меню на мобильных |
| Обложка | Первый экран с оффером и CTA-кнопками |
| О нас | Рассказ о глэмпинге и преимуществах |
| Номера и цены | Табы по категориям (шатры, ёлочные домики, семейные домики) с карточками номеров, ценами и кнопкой «Выбрать» |
| Активности и услуги | Активности гостям (костёр, рыбалка, каякинг и т.д.) со SVG-иконками |
| Отзывы гостей | Слайдер отзывов с перетаскиванием и инерцией |
| Бронирование | Форма брони с клиентской валидацией (имя, телефон с маской, даты заезда/выезда, номер, гости, согласие) и экраном «Заявка отправлена» |
| Как добраться и контакты | Маршрут, адрес, телефон, почта, Telegram/VK и встроенная карта Яндекса |

## Структура репозитория

```
glamping/
├── index.html          # весь лендинг: разметка, стили и скрипты в одном файле (~2200 строк)
└── assets/
    ├── icons/          # SVG-иконки (костёр, рыбалка, каякинг, телефон и др.)
    └── img/            # фотографии глэмпинга (в index.html подключены с CDN Тильды)
```

Примечание: в `index.html` изображения подключены по URL `static.tildacdn.pub`; локальные копии в `assets/img/` — резервные/исходные файлы.

## Возможности

- **Адаптивная навигация** — прозрачная над обложкой, светлая после прокрутки; высота шапки учитывается при плавном скролле к якорям (`window.vbNavOffset`)
- **Табы номеров** — переключение категорий с поддержкой клавиатуры (роль `tablist`/`tab`/`tabpanel`, ARIA)
- **Слайдер отзывов** — drag-to-scroll с инерцией (`requestAnimationFrame`)
- **Форма бронирования** — валидация на клиенте, маска телефона `+7 (___) ___-__-__`, динамические `min`-даты (выезд не раньше заезда), интеграция с Тильдой через `window.tildaForm.validate/showErrors` и `t_forms__initBtnClick` при наличии
- **Без внешних зависимостей** — ни npm, ни фреймворков; всё в одном HTML-файле

## Локальный запуск

Сборка не требуется. Достаточно открыть файл в браузере:

```powershell
start .\index.html
```

Либо через локальный статический сервер (например, встроенный в Python):

```powershell
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Разработка

- Весь контент, стили и скрипты живут в `C:\Programing\tilda\glamping\index.html`; каждая секция инкапсулирована в своём `<section>` со стилями и скриптом внутри, что упрощает перенос секций в конструктор Тильды по отдельности.
- Используемые CSS-переменные Тильды: `--t-text-font`, `--t-headline-font` — подставляются автоматически при публикации на Тильде.
- Основная цветовая палитра: зелёный `#3C5A3E`, терракота `#B4602F`/`#8A4A20`, кремовый `#F6F0E4`.

## Публикация

1. Создайте проект на Тильде и добавьте секции (каждая секция лендинга самодостаточна — HTML + её собственные стили/скрипты).
2. Замените контактные данные-заглушки (`+7 (900) 123-45-67`, `hello@pinewood-glamp.example`) на реальные.
3. Подключите отправку форм Тильды (или другой бэкенд) — сейчас при отправке показывается экран «Заявка отправлена» без реальной передачи данных, если `window.tildaForm` недоступен.
